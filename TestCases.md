# Тест-кейс: Проверка создания сущности: POST /api/create
**Идентификатор тест-кейса:** TC-001<br>
**Приоритет:** Высокий<br>
**Модуль:** Тестирование точек доступа для управления сущностями<br>
**Автор:** Карина Анастасия

## Описание
Тест-кейс проверяет создание новой сущности с использованием POST-запроса.

## Шаги выполнения
1. Сгенирировать тело запроса.
2. Создать сущность, отправив POST-запрос на endpoint "/api/create".
3. Проверить, что статус код ответа 200.
4. Получить id из ответа.
5. Получить по id новую сущность, отправив GET-запрос на endpoint "/api/get/{id}".
6. Проверить, что id ответа совпадает.
7. Проверить, что остальные параметры из ответа совпадают со сгенерирыванным запросом.

## Постусловие
Удалить сущность, отправив DELETE-запрос на endpoint "/api/delete/{id}".

## Ожидаемый результат
Новую сущность можно получить с помощью GET-запроса.

## Фактический результат
Новую сущность можно получить с помощью GET-запроса.

## Статус
Passed

## Примечания
